BigBlueButton is an open-source web conferencing system designed for online learning. It supports real-time sharing of audio, video, slides, chat and screen, plus polls, breakout rooms, multi-user whiteboards and session recording.

To enable this app, the cal.com admin must set the BigBlueButton server URL and shared secret in the admin settings (see `bbbctl conf --secret` on the BBB server).
