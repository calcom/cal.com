Burki is an AI voice assistant platform. Connect Cal.com so an assistant can check available times and book an appointment after the caller confirms their details.

A Burki workspace administrator connects a Cal.com API key and chooses a supported personal event type. Scheduling actions are enabled separately for each assistant. The connection and appointment type are shared across the workspace.

### Set up the connection

1. Create a Cal.com API key in your account settings. Keep it private.
2. Open **Integrations** in Burki, select **Cal.com**, and connect the key.
3. Select a supported **Workspace appointment type** and save it.
4. Open a saved assistant's **Actions** tab, add Cal.com, and enable the scheduling actions it needs. Configure the assistant to confirm the caller's time and details before booking.

Follow the [Cal.com setup guide](https://burki.dev/integrations/calcom/setup) for prerequisites, testing, troubleshooting, and disconnecting.

### Before a live call

Browser practice simulates calendar actions and does not create real appointments. Use an authorized telephone test and verify the appointment in Cal.com before relying on the workflow.

The integration supports ordinary personal event types requiring attendee name, email, and time zone. Team scheduling, cancellation, and rescheduling are not supported by this connection.

Burki voice usage is billed according to its [pricing](https://burki.dev/pricing). Your Cal.com plan must support the features you use.
