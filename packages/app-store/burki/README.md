# Burki

External-link automation entry for Burki's existing Cal.com API-key integration.

## Installation

Open [Burki's Cal.com setup guide](https://burki.dev/integrations/calcom/setup), then choose **Open Cal.com in Burki**. A workspace administrator connects their Cal.com API key, selects a supported personal event type, and enables scheduling actions on each assistant.

This entry links to Burki's setup guide. It does not collect credentials, create a Cal.com OAuth client, or add server-side handlers in this repository. Users configure their key privately in Burki.
