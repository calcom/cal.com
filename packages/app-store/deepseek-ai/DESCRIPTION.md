# DeepSeek AI Integration for Cal.com

Automate scheduling workflows, AI meeting preparation, and intelligent booking routing using DeepSeek AI models.

## Key Features
- **Smart Booking Briefs**: Automatically analyze invitee responses using DeepSeek reasoning models.
- **AI Agent Scheduling**: Connect DeepSeek-R1 and DeepSeek-V3 to your Cal.com booking links.
- **Seamless Setup**: Easily configure API endpoints for automated booking workflows.
